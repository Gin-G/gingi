Hi,
I wanted to pass along the link to this repo :
https://github.com/NicholasCote/k8s-argo-codespace

If you fork that into your personal account and then start a GitHub
codespaces it will automatically launch a Kubernetes cluster that you can
play around with. The README.md file provides a walkthrough on how to
install an Argo CD instance and then a simple Flask application.

If you're interested in setting up something locally afterwards I'd suggest
looking at minikube <https://minikube.sigs.k8s.io/docs/>or K3s
<https://k3s.io/>.

hesitate to reach out if I can be of any help.
