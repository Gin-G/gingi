Terminology

   -

   Element. For the purposes of this document, Element generally refers to
   the deliverables that are added onto the base OS in order to make it become
   Element OS proper. This includes things like sfapp, sfsvcmgr, sfconfig,
   WebUI, etc.
   -

   ElementOS. This is essentially the final deliverable shipped by
   SolidFire. This is the final product resulting from taking an underlying
   Linux OS, adding our kernel, all our 3rd party libraries, and all
the Element
   deliverables.
   -

   Ember. This is the SolidFire qualified Linux distribution developed and
   maintained by the platform team. This OS will serve as the base Linux OS
   that downstream SolidFire products will ship on.
   -

   Ember Build. This is the build infrastructure used to bootstrap and
   build the Ember Linux OS itself. This has nothing to do with the build
   process used to build ElementOS.
   -

   Ember Flavor. Ember Build has the ability to produce various flavors based
   on particular recipes and list of packages to be installed. Our initial
   thoughts around the required flavors will be: Minimal, HCI Compute Node,
   Storage Node, Management Node
